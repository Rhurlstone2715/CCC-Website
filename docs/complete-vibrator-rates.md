# Complete concrete vibrator rental rates

Daily KYD35, weekly KYD150, monthly KYD500 for the complete motor + one shaft + one head. Both shaft lengths (14′ and 20′) and head sizes (13/16″ and 1″) use the same complete rate.

The motor's catalog record carries the complete rate. The four included shaft/head records have zero additional charge for all three terms. Their existing IDs, quantities, set roles and compatibility remain unchanged, so complete-set validation and individual component inventory still apply. The existing server-authoritative pricing and customer-facing single cart line already sum the set components; no new pricing calculation is introduced.

The migration updates only these five products' future rates. Saved bookings, estimate/receipt PDFs, rewards records, companies and accounts are not rewritten. New database seeds contain the same complete rates.

The display category formerly labelled Hydraulic Tools is now Rebar Benders/Cutters. Its stable category URL (?category=hydraulic) and underlying booking classifications are retained.

Checks cover all four shaft/head combinations across daily/weekly/monthly terms, quantity multiplication, real checkout for each term, preserved stock/set metadata and unchanged earlier booking totals/PDFs.
